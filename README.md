# GSP920 – Securing a Cloud SQL for PostgreSQL Instance

Run the three scripts in order from Cloud Shell. They use the active `gcloud` project/account and do not contain lab credentials.

1. CMEK, KMS, and Cloud SQL instance
2. pgAudit, audit configuration, and sample database
3. Cloud IAM database user, grants, and verification

Cloud SQL creation/restart can take 20–35 minutes overall.
